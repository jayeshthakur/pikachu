# Pikachu

Daily-updated Pikachu facts and news, generated automatically from
[PokeAPI](https://pokeapi.co/) and live web search.

- `content/habits/` — Pokédex flavor-text entries on Pikachu's behavior and habitat
- `content/powers/` — Abilities and moves
- `content/daily_news/` — Recent Pikachu/Pokémon news

Content is unique per 7-day cycle (no repeats within a cycle), and the
cycle purges and restarts weekly. News articles are never repeated,
even across cycles.
